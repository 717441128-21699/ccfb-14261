# 显微标本照片反卷积复原工具

替代「一个滑块拉满就白边」的锐化:对每台显微镜、每个倍率先拍微孔光源照片**实测点扩散函数(PSF)**,标本照片按设备+倍率自动套用对应 PSF 做 **Richardson-Lucy 反卷积**,迭代过程用 **TV(全变分)正则**压住噪声和刚毛/触角节边缘的振铃。计算全部在浏览器本地完成(WebGL2),照片不出本机。

## 运行

```bash
npm install
npm run dev        # 开发服务器,按提示打开 http://localhost:5173
npm run build      # 产出静态文件到 dist/,可放到任意静态服务器
npm test           # 离线验证(已知真值,PSNR 提升 ≥ 6 dB)
```

需要支持 WebGL2 + 浮点渲染目标(EXT_color_buffer_float)的浏览器,桌面版 Chrome / Edge / Firefox 均可。

## 工作流程

1. **PSF 校准**:每台显微镜每个倍率拍一张微孔(针孔)光源照片 → 「PSF 校准」页导入 → 自动去背景、质心定位、亚像素对中裁窗、180° 对称化降噪、归一化 → 填写显微镜与倍率建档(存 IndexedDB,按设备归档)。
2. **标本复原**:选择显微镜+倍率(自动匹配已建档的 PSF)→ 把标本照片拖入批量队列 → 先用「预览」在小画布上快速试算,**每一轮迭代的结果都保存在胶片条里可逐帧回看**,配合「对比原图」找到刚毛清晰、振铃刚要起来的那一轮 → 一键把该迭代数设为导出参数 → 「开始批量处理」按全分辨率分块跑 GPU 反卷积并逐张导出 PNG,队列有逐块/逐迭代的进度条。
3. **验证与基准**:GPU 自检(GPU 与 CPU 参考实现结果对比)、2000 万像素 × 30 次迭代的性能基准。

## 算法

- **反卷积**:Richardson-Lucy 迭代,TV 以耦合形式进入乘性更新(Dey et al.):`x ← x·(Hᵀ(y/Hx)) / (1 − λ·div(∇x/|∇x|))`,在放大信号的同时抑制噪声与吉布斯振铃;Biggs-Andrews 加速(α 由相邻两次修正量的内积自适应,上限 0.9)显著加快收敛。
- **卷积**:FFT 加速。GPU 端为基-2 Cooley-Tukey(位反转 + 蝶形 pass,RG32F 浮点纹理),画布 2 的幂,默认 4096(显存不足可切 2048)。
- **大图分块**:任意尺寸图像切成带重叠边缘(PSF 支撑区 + 64px 振铃余量)的块分别反卷积,中心区域拼回,边界无接缝。
- **边界处理**:边缘渐隐(edgetaper)抑制边界截断振铃。
- **PSF 提取**:背景中位数扣除 → 30% 峰值阈值 → 加权质心 → 亚像素双线性对中裁窗 → 截负 → 180° 旋转对称化 → 和归一化。

## 验证结果(`npm test`)

- **FFT**:正逆变换往返误差 < 1e-10;GPU 蝶形/位反转的索引数学用纯 TS 模拟与 CPU 参考对拍一致。
- **PSF 校准**:模拟微孔光源图(高斯 σ=3 + 噪声)提取的 PSF 与真值 NCC > 0.98,质心误差 < 1.5 px。
- **反卷积**(512×512 合成标本图:刚毛、触角节、点阵、星形靶,特征宽 3 px):4 种 PSF × 3 种噪声水平共 12 组,80 次迭代,全部满足 **PSNR 提升 ≥ 6 dB**:

| PSF | 无噪声 | 轻噪声 σ=0.003 | 中噪声 σ=0.006+光子 |
|---|---|---|---|
| 高斯 σ=1.0 | +6.75 dB | +6.97 dB | +6.35 dB |
| 艾里斑(第一暗环 2.5px) | +9.04 dB | +9.33 dB | +7.89 dB |
| 运动模糊 7px/30° | +14.38 dB | +13.68 dB | +10.59 dB |
| 离焦圆盘 r=2.5 | +10.30 dB | +9.94 dB | +8.59 dB |

> 注意:更强的模糊(如高斯 σ≥1.5)或更重噪声下,高频信息被物理性截断,6 dB 在数学上不可达——这正是要按每台显微镜/倍率实测 PSF、并逐轮回看迭代过程选最佳轮次的原因。

## 性能

2000 万像素(5472×3648)× 30 次迭代的目标为 20 秒内。在「验证与基准」页可实测:4096 画布下全图分 2 块,中端独显通常 8–15 秒;核显/旧卡可切 2048 画布。实测耗时取决于 GPU,以基准页报告为准。

## 目录结构

```
src/core/    算法核心(纯 TS,Node 可测):FFT、RL-TV 反卷积、PSF 模型/校准、合成图、噪声、指标
src/gpu/     WebGL2:GL 基础设施、GPU FFT、GPU 反卷积器、分块/预览驱动
src/app/     界面:PSF 库(IndexedDB)、批量队列、图像 IO、主逻辑
test/        vitest:反卷积验证矩阵、PSF 校准、GPU FFT 索引数学模拟
```
